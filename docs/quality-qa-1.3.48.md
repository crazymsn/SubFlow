## 问题与修复

在用户提供的 120.3 秒、3456 × 2160 中文视频转英文配音案例中，原输出有 18 条字幕事件采用逐句缩放，最小缩到 46%；56 段配音中有 36 段需要超过 1.3 倍加速，最严重为约 4.67 倍。

- 字幕按样式固定字号，超长内容分页；分页只影响显示，不切割送给语音模型的语句。
- 临近字幕先组成较完整的语句，再根据时长整理口语稿。字幕与配音使用相同译文。
- 短语音不再强行减速填满字幕时长；只允许最高 1.25 倍的加速，超限明确报错。
- 自动参考音频仅在完整匹配识别句时附带逐字稿；稳定 GPT-SoVITS 采样参数，避免错误提示文本和碎片化合成干扰语调。
- 更新处理和音频缓存版本，防止复用旧的强制变速结果。
- 中文参考音色转英文改为优先 Qwen3-TTS；修复在两种配音语种之间切换时，引擎名称和端口控件不刷新的问题。

## 实际成片验证

使用本机 NVIDIA RTX 3060 Laptop GPU，先用 GPT-SoVITS 验证时间拟合，再对照 Qwen3-TTS 的英文发音，最终成片采用 Qwen3-TTS。原始视频未被覆盖，两个原始文件的 SHA-256 均保持一致。样片配音稿结合画面人工核对了 Jina、Markdown、PubMed 等专有名词，并整理了口语表达；这项人工校对不代表系统能够自动纠正所有识别和翻译错误。

| 检查 | 结果 |
| --- | --- |
| 分辨率、成片时长 | 3456 × 2160，120.32 秒（原视频约 120.3 秒） |
| 字幕字号 | 英文 108、中文 76；无逐句缩放指令 |
| 字幕安全宽度 | 所有事件通过宽度检查；抽查 8 个时间点画面 |
| 配音组织 | 56 个短片段合并整理为 19 段 |
| 实际变速 | 15 段保留模型原速，4 段微调；最大 1.1471 倍 |
| 音轨 | 成片含完整音轨，各段未与下一段重叠 |
| 语音复核 | GPU Whisper 重新识别完整成片；此前明显读错的网页内容和操作说明得到改善，未发现整句漏读 |

## 自动验证范围

- 第一轮全量回归：1,395 项通过、3 项跳过。调整英文模型后再次全量执行，1,393 项通过、3 项跳过；两项失败涉及旧模型预期与语种切换控件刷新，已更新对应断言并修复刷新逻辑，相关 71 项复测全部通过。第二轮覆盖率 92.10%。
- 固定字号检查覆盖 4 种分辨率与中英、英中、英文单语模式，检查长短句和分页。
- 使用实际 WAV / FFmpeg 验证短语音不被拖慢、适度加速有效、极端变速被拒绝且保留已有文件。
- Windows 冻结客户端通过自检、独立识别 worker 导入、FFmpeg / ffprobe 和下载取消验证。

以上结果验证了本案例和回归覆盖范围，不能替代对所有视频、音色和语言的试听。ASR 或翻译错误仍需校对；Apple M1 的真实语音质量和 GPU 验收由用户另行完成，本次未进行 Mac 实机测试。

在线配音稿整理曾成功返回完整稿件；最后一次对更保守字数预算的真实接口复测，在四次请求重试后返回翻译服务超时。因此不能宣称最新默认流程已在在线服务上完成无故障全流程验收。交付视频使用人工复核的稿件，实际本地 GPU 合成、时长拟合和导出均已完成；新任务的翻译和配音稿整理仍取决于配置的在线服务是否可用。
