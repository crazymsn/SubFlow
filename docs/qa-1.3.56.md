# 1.3.56 顶栏与待机任务区修正

> 历史记录：此文件保留当时的结果和版本状态，不代表当前安装包。最新使用说明见[文档索引](README.md)。

- 左侧品牌与窗口标题恢复为“SubFlow 语幕”；“深度云创科技”在整个顶栏中央，保留 `https://nav.meding.site` 链接，两者使用一致的标题字体。
- 待机保留任务标题、等待状态、0% 和进度条，只有日志框内部显示硬件检测与实际型号。后台预热信息不会覆盖这个待机视图，启动任务后切换为任务日志。
- 本机实际读到 `NVIDIA GeForce RTX 3060 Laptop GPU`。Windows 使用系统显卡接口与 CUDA 驱动读取名称，无需安装 Torch 或调用 PowerShell；无 CUDA 的显卡显示型号并注明 CPU 处理。
- Mac 读取系统报告的 Apple M 芯片名称，读取失败时不编造型号。该功能不改变实际推理设备的选择；硬件被识别也不等于模型已在 GPU 上运行。
- 窄窗口任务区增加必要高度，避免恢复状态栏后将显卡型号挤出可见区域。

验证：112 项相关测试通过，Ruff 通过；覆盖八种界面语言、四种窗口尺寸、公司标题居中、完整型号可见、开始/恢复/下载/试听及状态切换。对 1280×800 和 960×640 的实际 Qt 渲染做了截图检查。Mac 型号读取分支通过模拟测试，本轮没有 Mac 实机结果。

本地客户端版本为 1.3.56；沿用现有模型和运行环境，未发布 GitHub / Mac 新安装包。

暂存包和原目录客户端自检均通过，冻结客户端报告了本机实际 RTX 3060 Laptop GPU 型号。原目录更新 10 个文件，用户配置、Cookies、媒体工具及模型清单保持一致；回滚文件保存在本机临时目录 `subflow-before-1.3.56`。随后清除暂存包和构建缓存，清理检查确认正式客户端及配置未改变。
