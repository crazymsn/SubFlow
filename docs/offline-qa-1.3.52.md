## 离线依赖修复

- Qwen 与 GPT-SoVITS 优先读取随包环境，避免寻找开发机 venv 和模型缓存。
- 模型按文件内容校验，ZIP / 7z 解压改变时间戳不会触发重新下载；校验缓存保存在用户目录。
- GPT-SoVITS 的英语依赖检查 NLTK ZIP 文件名：同时提供合法 ZIP 与解压词典，修复“已有词典仍尝试联网”的问题。
- 韩语前端改用已打包的 `python-mecab-ko` 与词典，移除上游在推理期间调用 pip 的行为及对应用目录的临时复制。
- 中、英、日、韩、粤前端均在空白配置、外网与安装器受限的条件下产生非空音素序列。
- 普通资源错误不再当作 GPU 故障重载 CPU；实际 CUDA / MPS 错误仍保留 CPU 回退。
