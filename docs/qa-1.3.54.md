# 1.3.54 本地验收

> 历史记录：此文件保留当时的结果和版本状态，不代表当前安装包。最新使用说明见[文档索引](README.md)。

环境：Windows x64，RTX 3060 Laptop 6 GB。Mac Apple M 与 Intel 的构建配置已经覆盖，未在本轮进行 Mac 构建或实机测试。

## 实际运行

- 独立打包的 Whisper 环境使用 CUDA 与隐藏 CUDA 后的 CPU 各识别一次，均产出有效字幕片段；测试模型为本机缓存的 `tiny`。
- 独立打包的 WhisperX 环境使用 CUDA 与隐藏 CUDA 后的 CPU 各识别一次，均完成识别和对齐；测试模型为本机缓存的 `medium`。
- WhisperX 通过客户端适配层定位随包解释器、关闭自动安装并调用识别，完整流程通过。该次依赖检查耗时 20.37 秒，总耗时 44.57 秒，证明旧 12 秒超时会误判正常环境。
- 输入为项目内许可明确的合成参考音频，模型使用已有缓存；不涉及用户视频或云端翻译费用。CPU 结果来自隐藏显卡的同一台 Windows，不替代另一台完全无显卡设备的测试。

## 回归与界面

- 翻译接口中断后从 `translate` 恢复：识别和静音检测各只执行一次，识别文件内容保持一致，最终字幕包含译文。
- Qt 后台任务真实信号链覆盖翻译失败、部分缺译、继续后成功；完成线程退出后才启用继续，成功后关闭重试入口。
- 已完成翻译但仍有缺译、随后其他阶段失败时，继续入口仍可恢复翻译。
- 视频任务保留 `qwen3-native` 和所选 `SubFlow_fr_male` 音色，测试不调用真实配音服务。
- 八种界面语言 × 四种窗口尺寸的 32 种布局通过。顶栏链接、待机 GPU 显示、暂停继续、取消和窗口关闭路径通过检查。
- WhisperX 解释器复用、冷启动检查时限、取消传播，以及完整包识别环境与旧包兼容通过测试。
- 全量 Ruff 检查通过。客户端 EXE 自检覆盖实际 Qt 界面、八语种路由、FFmpeg / ffprobe / uv 及独立下载工作进程。

初轮测试中两个测试夹具需要修正：模拟译文的语言必须匹配目标语言；像素对齐检查必须显式使用浅色主题，避免前面的深色主题测试污染。修正后针对性复验通过，没有放宽字幕对齐的数值阈值。
