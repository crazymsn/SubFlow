## 修复结果

1. 中文原片输出简体或繁体中文始终保留原声；残留配音开关不会强制触发 TTS。源语言下拉框误设及少量英文术语也不会覆盖中文原始转写的主要语种。
2. 简繁转换继续应用于字幕。中英双语字幕仍需要翻译接口，中文单行字幕不需要；跨语种配音规则保留。
3. 修复长视频混音的 Windows 命令长度问题：每批最多 24 个音频输入，滤镜内容写入临时文件，多级合并保留片段起点、重叠和视频末尾静音。
4. 配音缓存纳入参考音频内容和字幕时长。取消或失败的时间适配不会留下可误用的半成品缓存。
5. 原声任务不再复用旧配音成片。缓存版本和重新导出的语种判断同步更新。
6. Windows 本地打包默认携带完整 GPT-SoVITS 环境，依赖安装、PyInstaller、模型复制失败都会终止构建。`-SourceOnly` 仍可显式生成开发用精简包。
7. 清理源码类型错误和导入检查错误，补全 GUI 构建器所创建控件的类型，修正配置映射、字体权重、播放器状态等类型问题。

## 验收范围

用户提供的是错误截图，没有原视频文件；真实端到端验收使用本地生成的中文短视频，长视频风险另由批量混音回归覆盖。Whisper tiny 用于验证流程，样片中的转写存在同音字误识别，不代表字幕文字已人工校对。

跳过项需要额外的本地回归视频。GPT-SoVITS 上游模型支持的配音语种仍受限，西班牙语、俄语、法语、德语配音会明确报不支持；字幕翻译不受这个限制。Whisper / WhisperX 识别环境与 GPT-SoVITS 推理环境仍分别管理。

本次验证的是 Windows 本地完整构建。现有 GitHub Actions 旧发布流程、macOS 构建及跨机器硬件组合未在本次执行发布验收；上游 GPT-SoVITS 全部训练功能也不属于此次推理集成测试。
